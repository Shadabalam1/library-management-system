# 📚 Library Management System

## 🚀 Features
- User Authentication (JWT)
- Role-based access (Admin/User)
- Book management
- Borrow & Return system

## 🛠 Tech Stack
- React + Vite
- Node.js + Express
- MongoDB

## ⚙️ Setup Instructions
### Client
cd client
npm install
npm run dev

### Server
cd server
npm install
npm run dev
